# Apiculture Management App

This project is a modern full-stack web application for apiculture management.

## Tech Stack
- **Backend:** Python FastAPI, SQLAlchemy, Alembic, SQLite, Admin panel
- **Frontend:** React + Vite (JavaScript)
- **Database:** SQLite (default, can be swapped)
- **DevOps:** Docker support

## Features
- CRUD for Articles, Categories, Types, and Article Names
- REST API design
- Admin panel for easy management
- Modern frontend with React and Vite

## Getting Started

### Frontend
```bash
npm install
npm run dev
```
